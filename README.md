## 📌 Project Overview

SNAP Research is a premium AI-powered research assistant that enables users to explore any topic deeply using multiple research modes — Explain, Deep Dive, Compare, and Synthesize. Built on Google Gemini 3.5 Flash via the official `google-genai` SDK with a Flask backend.

---

## 🚀 Quick Start

```bash
# 1. Clone / navigate to project
cd 09_Source_Code

# 2. Activate virtual environment
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # Mac/Linux

# 3. Install dependencies
pip install -r requirements.txt

# 4. Add your API key to .env
GEMINI_API_KEY=your_key_here

# 5. Run the server
python app.py

# 6. Open browser
http://localhost:5001
```
